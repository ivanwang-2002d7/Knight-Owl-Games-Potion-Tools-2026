## 🎮 About the Game

Shelve the Potions! is a casual indie simulation and puzzle game developed by Knight Owl Games. It released on August 24, 2026. Players explore an enchanted cellar and return more than 2,000 potions to their shelves by discovering the unique sorting rule for each handcrafted puzzle.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Shelve the Potions!**. This trainer enhances the game's relaxing sorting and exploration loop with adjustable movement speed, expanded carrying capacity, unlimited magical assistance, potion highlighting, solution reveals, and faster collection abilities.

**Target Audience:** Players who want a more convenient and accessible way to organize the potion shelves, explore the enchanted workshop, solve environmental clues, or replay the game without repetitive collection tasks.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement speed multiplier to shorten trips between shelves, clue stations, and scattered potion groups. Unlimited sprint is useful when crossing the workshop or checking distant areas for missing puzzle objects.

### Tools & Inventory

Expanded carrying capacity reduces the need to make several trips while collecting bottles, books, chess pieces, clock parts, flowers, and other clue items. Use auto-collection when clearing a dense group of potions from the floor.

### World & Environment

Explore the cellar carefully because some shelf solutions depend on clues found elsewhere in the workshop. Potion highlighting can help locate missing objects, while unlimited cat hints and solution reveals provide assistance when environmental puzzles become difficult.

### Combat & Weapons

Shelve the Potions! has no combat system. The trainer focuses on sorting, exploration, puzzle assistance, movement, carrying capacity, and collection convenience.
